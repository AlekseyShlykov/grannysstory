# Как расширять и обновлять историческую базу

## Конвейер

```
внешний архив → collect/ → авторские JSON (data/…) → validate/ → normalize/ (SQLite) → export/ (public/data/world) → игра
```

| Шаг | Команда | Что делает |
|---|---|---|
| Сбор координат | `npm run data:world:collect` | Скачивает из Wikidata (CC0) координаты и подписи для всех узлов с QID, кеш в `data/cache/wikidata/entities.json`. Единственный шаг с сетью. |
| Проверка | `npm run validate:world` | Схема, даты и их точность, масштаб ↔ уровень места, существование места в период события, временная иерархия до государства, периоды названий, источники и URL-доказательства, статистика, дубликаты, сверка координат с Wikidata. Ошибка блокирует сборку. |
| Полный прогон | `npm run data:world` | Проверка → `data/research/historical.sqlite` → браузерные пакеты, `docs/VALIDATION_REPORT.md`, `docs/COVERAGE_REPORT.md`. |
| Сборка игры | `npm run build` | Включает `validate:world`; нужен `python3` (3.8+, только стандартная библиотека). |

Во время игры внешние сервисы не вызываются. Браузер получает встроенный реестр мест и манифест, а пакеты событий загружает только для узлов, через которые проходит жизнь героини (место и все его административные родители на каждую дату), кеширует их в IndexedDB; Service Worker кеширует оболочку.

## Добавить запись

1. Найдите факт в надёжном источнике и откройте страницу. Зарегистрируйте источник в `data/sources/<cc>.json` (лицензия, условия, способ доступа).
2. Добавьте событие в подходящий файл `data/historical/<страна>/{national,regions,cities}/…json` по схеме из [SCHEMA.md](SCHEMA.md): собственный пересказ на русском, точность даты как в источнике, масштаб по реальной географии, `evidence` с URL и датой доступа.
3. `npm run data:world`, затем `npm test`.

Не заполняйте пробелы выдуманными местными событиями. Если о месте ничего нет, движок честно откатится к региональному и национальному контексту, а отчёт покрытия покажет пробел.

## Добавить место

1. Добавьте узел в `data/locations/<cc>.json`: стабильный `id`, QID, тип, `settlement_class`, местные и русские названия с периодами (и форму «в …» для речи), родителей с датами. Смену границ и подчинения записывайте сменой родителя; военную оккупацию — в `occupations`.
2. `npm run data:world:collect`, чтобы подтянуть координаты.
3. Порог для стартового меню считается в `export.py` (`GATE_*`): ≥8 собственных записей и ≥2 пригодных события в каждом десятилетии 1920–2020-х. Пункт меню дополнительно требует художественного текста региона (см. `docs/decisions.md`, D-010).

## Обновить набор

- Измените `WORLD_DATASET_VERSION` в `export/export.py` при любом изменении опубликованных записей: браузер сравнивает версию пакета с манифестом и перезагрузит устаревший кеш.
- Сохранённые жизни не ломаются: уже рассказанные исторические эпизоды хранятся в сохранении, а при сдвиге пула не повторяются в следующих пятилетиях.
- ID событий и мест не переиспользуются и не переименовываются. Ошибочную запись удаляйте или переводите в `needs_review`.

## Чувствительные записи

`sensitive: true` (репрессии, массовая гибель, преследования, насилие) экспортируются, но не озвучиваются бабушкой и не становятся рамкой развилки, пока редактор не проверит их сценарное использование. Снятие флага — решение человека, не скрипта.
