# Движок биографии

## Вход

`StartSelection` неизменяем: регион рождения, год рождения, seed, версия данных, год разговора. Год разговора выводится как `min(birthYear + 100, manifest.conversationYear)`; сейчас манифест ограничивает его 2026 годом. Комбинация проходит проверку манифеста до генерации, поэтому сохранение не может содержать будущее относительно своего интервью.

## Детерминизм

Вся вариативность биографии использует один seeded PRNG. `crypto.getRandomValues` применяется только для создания нового seed. Сохранение содержит и seed, и полный канонический state; повторная генерация не заменяет сохранённые решения.

## Семья

Генератор создаёт один из четырёх графов: биологическая бабушка, приёмная бабушка, сестра бабушки/дедушки или двоюродная бабушка. Прямые графы связывают героиню с родителем игрока; боковые проводят путь через её сестру/брата или двоюродного родственника. Возраст каждой связи взрослый → ребёнок проверяется.

В боковом графе героиня может осознанно не иметь детей, хотеть их без результата, отложить решение до изменения обстоятельств, не придавать вопросу большого значения или стать важным взрослым для чужих детей. Для бездетной героини валидатор запрещает исходящее от неё родительское ребро.

## События и последствия

`LifeEvent` хранит год, место, участников, provenance, источники, значимость и видимость. `BranchState` до ответа не имеет исхода. `commitBranch` допускает только первый исход или повтор уже выбранного исхода; попытка заменить его приводит к ошибке.

`MemoryState` хранит независимые качества гордости, сожаления, благодарности и принятия. Они являются логическими характеристиками интерпретации, а не видимым счётом.

Переезд меняет `residenceHistory`; атлас не создаёт маршруты из текста. Исторический контекст включается только для конкретного места. Для блокады отдельно хранится флаг присутствия в городе; рождение в Ленинграде само по себе не означает пребывание там в период блокады.

## Проверяемые инварианты

- непрерывный прямой или боковой семейный путь к игроку;
- отсутствие вымышленных потомков у бездетной героини;
- события не раньше рождения и не после разговора;
- отсутствие пересечения постоянных резиденций;
- существующие placeId;
- исторические названия по году;
- необратимость раскрытой развилки;
- атлас показывает только известные события.
