# Архивные ссылки и готовность городов (world-1.3)

Сгенерирован `scripts/historical-data/export/export.py` 2026-11-13, набор `world-1.2.0`. Охват 1900–2020. Доля архивных ссылок = события, у которых есть ссылка на страницу архива или официального органа о том же событии (государственный и муниципальный архив, библиотека и архив газет, правительство, парламент и официальный вестник, статистика, государственный музей, университет), / все проверенные события; считаются различные события, для города — только его собственные. Минимум 55% (решение владельца 13.11.2026). Wikipedia в долю не входит.
