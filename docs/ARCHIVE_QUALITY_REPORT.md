# Архивное качество и готовность городов (world-1.3)

Сгенерирован `scripts/historical-data/export/export.py` 2026-11-13, набор `world-1.2.0`. Охват 1900–2020. Доля первичных архивных подтверждений = события с хотя бы одним доказательством `primary: true` (названный документ: газета, муниципальная запись, закон, перепись, ежегодник, фото с метаданными и т. п.) / все проверенные события; считаются различные события, для города — только его собственные. Минимум 55%, цель 70%. Wikipedia в долю не входит и не может быть единственным источником.
