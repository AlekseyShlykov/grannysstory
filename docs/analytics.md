# Прохождения в Google Таблице

Игра отправляет анонимные данные о прохождении: одну строку, когда разговор доходит до очередного пятилетнего этапа, и одну, когда открывается финальный экран. По таблице видно, сколько людей дошло до каждого этапа и на каком этапе они уходят. Код отправки: `src/app/progressReport.ts`; решение: `docs/decisions.md`, D-031.

## Что приходит в таблицу

| Столбец | Что это |
|---|---|
| Получено | время получения строки (часы Google) |
| Время у игрока | время события в браузере игрока, UTC |
| Прохождение | случайный идентификатор одной жизни (seed) |
| Игрок | случайный идентификатор браузера; объединяет несколько прохождений одного человека |
| Событие | `stage` — дошёл до этапа, `finished` — открылся финальный экран |
| Этап | номер этапа, начиная с 1; на финальном экране равен «Всего этапов» |
| Всего этапов | сколько пятилетних этапов в этой жизни (зависит от года рождения) |
| Год в игре, Возраст героини | начало этапа |
| Закончил | `TRUE` только у строки `finished` |
| Язык | язык интерфейса в момент события: `ru`, `en`, а новые языки появятся сами, когда их добавят в игру |
| Место рождения, Год рождения | выбор на стартовом экране |
| Версия данных | версия исторического набора |

Текст разговора, сгенерированная жизнь и голоса за события не отправляются.

## Лист «Игроки»: один игрок, одна строка

Скрипт сам ведёт второй лист со сводкой и обновляет строку игрока при каждом новом событии.

| Столбец | Что это |
|---|---|
| Игрок | случайный идентификатор браузера |
| Прохождений | сколько разных жизней он начинал |
| Закончено прохождений | сколько из них дошло до финального экрана |
| Последнее прохождение | идентификатор самого свежего прохождения |
| Дошёл до этапа, Всего этапов, Пройдено | прогресс в последнем прохождении; «Пройдено» = 100%, если оно закончено |
| Год в игре, Возраст героини | этап, до которого он дошёл |
| Закончил последнее | да / нет |
| Язык, Место рождения, Год рождения | из последнего прохождения |
| Первый раз, Последний раз | время первого и последнего события |
| Версия данных | версия исторического набора |

Два последних столбца служебные и скрыты: в них списки прохождений игрока, по ним считаются счётчики.

Если строки на листе «Игроки» разошлись с событиями (например, после ручного удаления строк) или скрипт обновили, когда события уже были, выберите в таблице меню «Granny's Story» → «Пересчитать лист „Игроки“». Сводка пересчитается по листу «Прохождения». Каждый этап одного прохождения отправляется один раз, в том числе после продолжения сохранённой игры.

## Подключение (один раз)

1. Создайте Google Таблицу.
2. Расширения → Apps Script. Удалите пример и вставьте содержимое `scripts/analytics/progress-sheet.gs`. Сохраните.
3. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение». «Выполнять от имени»: я; «У кого есть доступ»: все. Разрешите доступ к таблице.
4. Скопируйте адрес веб-приложения (`https://script.google.com/macros/s/…/exec`).
5. Впишите его в `PROGRESS_SHEET_URL` в `src/app/progressReport.ts` (или задайте переменную сборки `VITE_PROGRESS_SHEET_URL`) и опубликуйте игру. Пока адрес пустой, игра ничего не отправляет.

## Обновление скрипта

1. Вставьте новую версию `scripts/analytics/progress-sheet.gs` в редактор Apps Script вместо старой и сохраните.
2. «Начать развертывание» → «Управление развертываниями» → карандаш у текущего развертывания → «Версия: новая версия» → «Развернуть». Адрес веб-приложения не изменится, в игре ничего менять не нужно.
3. Если события уже копились до обновления, один раз выполните `rebuildPlayers` (в редакторе выберите функцию и нажмите «Выполнить», или меню «Granny's Story» после перезагрузки таблицы).

## Полезные формулы

На отдельном листе:

- Сколько прохождений дошло до каждого этапа:
  `=QUERY(Прохождения!A:N; "select F, count(C) where E = 'stage' group by F label F 'Этап', count(C) 'Прохождений'"; 1)`
- То же по языкам:
  `=QUERY(Прохождения!A:N; "select K, F, count(C) where E = 'stage' group by K, F label K 'Язык', F 'Этап', count(C) 'Прохождений'"; 1)`
- Сколько прохождений закончено, по языкам:
  `=QUERY(Прохождения!A:N; "select K, count(C) where E = 'finished' group by K label K 'Язык', count(C) 'Закончено'"; 1)`

Число этапов зависит от года рождения героини (около 17–21), поэтому для сравнения жизней разной длины удобнее смотреть долю: «Этап» / «Всего этапов».
