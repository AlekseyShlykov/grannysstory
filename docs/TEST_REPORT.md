# Отчёт о проверках

Дата: 29 октября 2026 года. Файл фиксирует только выполненные проверки.

| Проверка | Статус | Результат |
|---|---|---|
| `npm run data:world` | пройдено | 101 место, 141 источник, 944 события, 166 контекстов; 0 ошибок, 0 предупреждений |
| Экспорт мирового набора | пройдено | 938 проверенных событий и 165 контекстов в 48 пакетах; 6 записей `needs_review` не экспортированы |
| Валидация встроенного слоя | пройдено | 56 событий, 5 мест и 45 источников |
| TypeScript | пройдено | `tsc --noEmit`, ошибок нет |
| Unit/UI tests | пройдено | 4 файла, 115 тестов |
| Симуляции | пройдено | 5000 биографий по пяти российским регионам; все четыре типа родства и пять вариантов бездетной линии |
| Production build | пройдено | Vite 8.3.5, 46 модулей, JS 580.29 kB / 156.88 kB gzip |

Тесты отдельно проверяют диапазон 1900–1940, формулу года разговора, 20 доступных локаций пяти стран, смену архивного списка, исторические названия, суверенитет и переходную администрацию Польши, детерминизм, сохранение, оба исхода развилок, хронологию, отсутствие повторов и смешение местного с национальным/международным фоном.

Отдельная проверка 500 seed подтверждает, что каждая из первых четырёх реплик реально получает не менее 20 вариантов, а вступление и воспоминания 0, 5 и 10 лет принадлежат одной выбранной линии. Структурный тест проверяет возвращение её мотива в 20, 30 и 60 лет.

## Ручной сквозной прогон в Chrome

| Режим | Результат |
|---|---|
| Desktop 1280 px, Лион, 1900 | разговор до 2000 года; 22 обмена, 45 эпизодов атласа, 19 исторических; архивы Франции; только вопрос и ответ |
| Mobile 390 px, Варшава, 1940, альтернативные ответы | разговор до 2026 года; 20 обменов, 41 эпизод атласа, 17 исторических; архивы Польши; только вопрос и ответ |
| Общие проверки | 20 локаций и 5 групп стран без `?preview=world`; годы 1900–1940; архивы свёрнуты; хронология вопросов не убывает; источники есть в атласе; горизонтального overflow и ошибок браузера нет |
| Связность, два новых seed Твери | две разные линии, «хлебное полотенце» и «маленькое зеркало», прошли до атласа; детали первых четырёх реплик продолжились в 20, 30 и 60 лет; по 47 эпизодов, ошибок браузера и overflow нет |

Ограничения: тесты подтверждают структуру и работу механизма, но не доказывают истинность каждой исторической записи. Не проводились проверка реальным скринридером, тест на физическом мобильном устройстве и редакционное тестирование независимыми носителями каждой культуры. Vite предупреждает, что основной minified chunk превышает 500 kB; это не блокирует сборку, но требует будущего code splitting.
