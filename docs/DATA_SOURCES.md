# Источники исторических данных

Российский реестр находится в `content/historical/sources.json`, реестры мирового набора — в `data/sources/<cc>.json`, а их опубликованное объединение — в `public/data/world/sources.json`. Дата проверки ссылок для текущего набора: 29 октября 2026 года.

Каталог ссылок для стартового экрана находится в `content/historical/archiveCatalog.json`. Он связывает страну и выбранный регион только с записями полного реестра; URL в интерфейсе не дублируются и не задаются вручную в компоненте.

## Национальный хронологический слой

Для заполнения пятилетних интервалов опубликованы 48 кратких записей 1904–2025 годов. Ранний слой 1904–1917 годов опирается на хронологию Президентской библиотеки; последующий слой использует Президентскую библиотеку для советских государственных, космических, медийных и инфраструктурных событий, Росстат для переписей, Координационный центр доменов .RU/.РФ для истории национальных доменов, Федеральное казначейство для даты запуска Госуслуг, Банк России для финансовых кризисов, Минтруд для семейного законодательства, МОК и FIFA для спортивных событий, МАГАТЭ для Чернобыля, ВОЗ для пандемии COVID-19 и ООН для события 2022 года. Каждая запись ссылается на элемент реестра; художественные личные воспоминания из этих источников не выводятся.

## Неиспользованные как данные источники

«Прожито», Истмат, Статистический музей, ГПИБ, ОБД «Мемориал», «Память народа», OpenList и РГАКФД перечислены в задании как приоритетные направления. В текущей короткой итерации из них не извлечены проверенные игровые записи. Проект не заявляет, что их фонды исследованы.

## Права

Игра содержит только краткие оригинальные пересказы дат и фактов со ссылками. Архивные сканы, фотографии, газетные тексты, дневники, свидетельства и цитаты не включены. Публичная доступность страниц не интерпретируется как лицензия на повторное использование материалов. Для каждого источника в реестре указан фактический способ использования.

Платный доступ, авторизация и CAPTCHA не обходились. Большинство новых записей опирается на Wikipedia как вторичный источник (`confidence: medium`); `high` получают записи, подтверждённые официальной статистикой, законодательными базами или архивами (INSEE, Légifrance, ONS, DfT, GUS, API правовых актов Сейма, Президентская библиотека и др.). Gallica, Archives nationales, British Library National Life Stories, Szukaj w Archiwach и NAC открывались для проверки официальных точек входа и редакционного направления, но их материалы не копировались и не использовались как доказательство конкретной игровой записи без отдельной ссылки в `evidence`. Polona, Library of Congress, IPUMS, «Прожито», РГАКФД и ряд других архивов остаются `catalogued`. Лицензии и условия по каждому ресурсу записаны в реестре так, как их поняли исследователи; это не юридическая экспертиза.
