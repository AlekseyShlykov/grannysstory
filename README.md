# Бабушка

Первая короткая играбельная вертикальная версия браузерной narrative-игры. Игрок выбирает место и год рождения бабушки или доверяет их случаю, после чего слушает новую детерминированно сгенерированную жизнь, узнаёт один ранее неизвестный поворот и в конце видит атлас рассказанной части биографии.

## Запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm test
npm run simulate
npm run build
```

`npm run build` сначала компилирует JSON-пакеты в `public/data`, затем блокирует сборку при ошибках источников, дат, географии, статуса проверки или неподтверждённых вероятностей.

## Что реализовано

- На старте можно выбрать одну из 20 локаций России, Франции, Великобритании, Польши и США и год рождения 1900–1940 либо запустить полностью случайную поддерживаемую комбинацию.
- Год разговора вычисляется отдельно для каждой жизни: год столетия, но не позднее текущего поддерживаемого года 2026. Поэтому для 1920 года история заканчивается в 2020-м, для 1927 года — в 2026-м в возрасте 99 лет.
- Первый вопрос простой: где и когда она родилась. Исторический фон звучит её словами (`content/scenes/historicalVoice.ts`), факты и даты остаются проверенными.
- Новая героиня и новый seed для каждого запуска; одинаковый seed даёт ту же жизнь.
- Четыре согласованных семейных пути: родная и приёмная бабушка, старшая боковая родственница и двоюродная бабушка; боковые пути допускают пять вариантов жизни без собственных детей.
- Восемь типов необратимых развилок; каждая связывает две человеческие ценности, а поздняя память может одновременно содержать гордость и сожаление.
- Хронологический разговор от рождения до вычисленного года интервью: одна точка каждые пять лет, завершающая текущая точка и отдельное уточнение после раскрытия поворотной ситуации, всего 20–22 ответа.
- Одна из 22 связных линий ранней памяти на каждую новую жизнь: первые четыре реплики развивают общий предмет, человека или привычку, а мотив возвращается в более поздние годы.
- На каждой точке личная память и переосмысление жизни соединяются с проверенным историческим фоном; событие выбирается по seed из пула крупных, культурных, технических и повседневных вех и не выдаётся за личный опыт.
- Во время беседы видны только вопрос и ответ; редакторские комментарии и провенанс остаются для итогового атласа.
- Разделение проверенного контекста и художественных личных событий.
- Локальное сохранение, продолжение и финальный атлас известных фактов.
- Исторические названия Тверь / Калинин / Тверь и Ленинград / Санкт-Петербург.
- Загрузка только выбранного статического регионального пакета, кеш пакета в IndexedDB и Service Worker для оболочки, без аналитики и внешних runtime API.

Это доказательство целостности эмоционального и технического ядра. Фактическая продолжительность ещё должна быть проверена на живых игроках; ограничения перечислены в [docs/CONTENT_COVERAGE.md](docs/CONTENT_COVERAGE.md).

## Структура

- `content/historical` — проверяемые исходные JSON-записи и реестр источников.
- `content/scenes` — оригинальные художественные тексты и развилки.
- `src/engine` — чистые функции генерации, диалога, сохранения и атласа.
- `src/app` — интерфейс.
- `scripts/verify` — блокирующая проверка данных.
- `tests` — логика, 5000 симуляций и UI smoke tests.

Игра не обращается к архивам или LLM во время прохождения. Данные, код и интерфейс работают со статической сборкой.

## GitHub Pages

Репозиторий содержит workflow `.github/workflows/deploy-pages.yml`. После однократного включения Pages каждый push в `main` проверяет данные, TypeScript-сборку и публикует `dist` с базовым путём `/grannysstory/`.

```bash
gh api --method POST repos/AlekseyShlykov/grannysstory/pages -f build_type=workflow # один раз
gh workflow run deploy-pages.yml --repo AlekseyShlykov/grannysstory                # при ручном запуске
```

После успешного workflow игра будет доступна по адресу `https://buildtounderstand.dev/grannysstory/` (Pages использует настроенный для аккаунта домен).


## Мировой исторический набор

Пять стран (Франция, США, Великобритания/Англия, Польша, Россия/СССР), 1900–2025: схема в [data/SCHEMA.md](data/SCHEMA.md), конвейер в `scripts/historical-data`, инструкции по расширению в [data/EXPANDING.md](data/EXPANDING.md), покрытие в [docs/COVERAGE_REPORT.md](docs/COVERAGE_REPORT.md).

```bash
npm run data:world:collect   # один раз с сетью: координаты Wikidata
npm run data:world           # проверка → SQLite → пакеты public/data/world + отчёты
```

Нужен `python3` 3.8+ без дополнительных пакетов. Места мирового набора попадают в основное меню только после порога исторического покрытия 1900–2025, отдельного вычитанного художественного текста и списка архивов страны (см. `docs/decisions.md`, D-008 и D-010).
