# Решения расширения, 16.11.2026

Требование владельца о прямой первичной опоре для ES, JP, BR, ZA, CD, EG заменяет ослабленный метод D-038 для этих шести стран. Старые авторские данные не пересчитываются и не удаляются. Доли считаются по уникальным событиям, отдельно город/страна/шесть стран; наследуемые события не увеличивают число городских записей.

Незаконченные города остаются researchOnly даже при наличии координат и JSON. Они недоступны на старте и как места переезда. Пакеты world-1.3.0; формат сохранения v2 сохраняется, раскрытые факты не меняются. Статистические method_note сохраняются при экспорте. Объём подтверждён владельцем: 18 явно перечисленных городов. Девятнадцатый город не требуется.
